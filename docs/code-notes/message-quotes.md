`packages/session/message-quotes/src/client/quote-text.ts:messageQuoteRanges` (finding 265): the matcher treated every line starting with a greater-than sign as a quote, so a transcript or code sample in a fenced block that contained `> result` was displayed as a quote preview with the marker removed. `fencedSpans` now finds backtick and tilde fences the CommonMark way (up to three leading spaces, an opening run of at least three, a backtick fence info string without backticks, a closing run of the same character at least as long with nothing after it, an unclosed fence running to the end of the text) and `messageQuoteRanges` drops any quote run that starts inside one. Fence-like lines inside a quote are not tracked, and the stored and model-visible message is never changed by this renderer.
