# config-editor code notes

`packages/boot/config-editor/src/index.ts:ConfigEditor::edit`: the profile lock only coordinates writers that take it, and an ordinary text editor does not, so a save landing after `edit` read `before` was overwritten by the replacement, and a save landing during runtime reconciliation was overwritten by the unconditional rollback to `before` (finding 124). `edit` now re-reads the patch file immediately before writing and refuses with nothing written when it differs from `before`. On a reconciliation failure it restores `before` only when the file still holds exactly the text this edit wrote; if anything else is there, the file is left alone (the external edit is the newer truth), the runtime is reconciled to what is on disk on a best-effort basis, and the error names the conflict with the reconciliation failure as its cause. A save in the instant between the last check and the atomic replace is still lost, since neither platform offers a compare-and-swap replace.
