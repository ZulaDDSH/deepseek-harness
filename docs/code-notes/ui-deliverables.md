# ui-deliverables code notes

`packages/client/ui-deliverables/src/present-open.ts:handleChangesSummary`, `packages/client/ui-deliverables/src/changes.ts:isChangesSummary` and `packages/client/ui-deliverables/src/client/ChangedFiles.tsx:ChangedFiles` and `packages/client/ui-deliverables/src/client/Deliverables.tsx:Deliverables`: the summary route serves a fixed field list, so the Host's `incomplete` marker (a snapshot skipped unreadable paths, issues.md finding 76) is added to that list and to the client validator as an optional `{ paths: string[] }`. An incomplete summary is drawn with the `changes.incomplete` title instead of the plain count, and `ChangedFilesDock` shows a card for an incomplete summary even when it lists no file, so a partial review never looks like a clean one. Covered by `packages/client/ui-deliverables/tests/changes-open.host.spec.ts` and `packages/client/ui-deliverables/tests/deliverables.client.spec.tsx`.
