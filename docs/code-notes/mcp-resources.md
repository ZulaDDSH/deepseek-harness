# mcp-resources code notes

`packages/mcp/mcp-resources/src/tools.ts:registerResourceTools` (finding 78): the MCP client rejects a `resources/read` over its fixed 8 MiB limit with an `McpLocalError` coded `MCP_RESOURCE_TOO_LARGE`, whose text names the URI and the byte counts but gives the model no next step, and a model may retry the same read. `read_mcp_resource` now catches that code and rethrows an `Error` that keeps the original message, states that the server's content cannot be read in full through this tool and that a retry returns the same result, and carries the original error as `cause`. The code is matched by its string value on the error's `code` property because this package does not depend on `@deepseek-ai/dsh-mcp-client`; any other error is rethrown unchanged. The list tools are not wrapped because listing results are paged and not size-capped.
