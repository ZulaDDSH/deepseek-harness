
`packages/session/session-projection/src/index.ts:SessionProjectionRegistry.drive` isolates each unit and each listener call: a throwing unit, invalid wire view, or throwing per-key or event listener is recorded and the drive continues with the remaining units and listeners, then rethrows the first recorded error so Session still reports it and the event stays committed. A unit that threw before advancing keeps its old observed sequence and catches up from the durable log on the next snapshot. Clients are not resynchronized for the failed unit's missed notification (finding 327 remainder), and an event listener still receives only the changes that were collected.
