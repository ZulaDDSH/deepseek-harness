# fs-local code notes

`packages/fs/fs-local/src/fsio.ts:applyLiteralEdit` (finding 23, issue #126): a sixth `append` argument appends the normalized `newString` to the LF-normalized content and returns one replacement, skipping the empty-search rejection that still applies to ordinary edits. `LocalFileSystem::editText` passes `edit.append` through, so appending runs under the same per-target lock, stale-version check, `readForEdit` size and binary checks, line-ending restoration and `writeFileAtomic` expected-version recheck that guard every edit; the guarded-mutation protection added for finding 4 is untouched because the write call is the same. An empty existing file takes the append (the content before is the empty string).

`packages/fs/fs-local/src/fsio.ts:restoreEditedText` (finding 315): `readForEdit` also returns the raw decoded text, and write-back no longer re-applies one line-ending style to the whole file. The edited LF-normalized text is compared with the LF-normalized original, the common prefix and suffix are kept as the original raw bytes, and only the changed middle is converted to the detected style, so lines outside the edit keep their own CRLF or LF endings (mixed files, and a move without hunks, write back the original bytes). `fsio.ts:detectLineEndings` now counts the whole file instead of the first 4096 characters, so a uniformly CRLF file whose first newline is far into the file is still CRLF for the inserted lines. The reported before and after stay LF-normalized because the whole-file conversion no longer happens. A lone `\r` at the edge of the changed span can combine with an adjacent `\n` into one CRLF on disk; that quirk existed before and is not addressed.

`packages/fs/fs-local/src/fsio.ts:applyLiteralEdit` (finding 316): the single-match guard now looks for a second occurrence starting one character after the first, so overlapping occurrences (`aa` in `aaa`) are ambiguous and raise `FS_AMBIGUOUS_EDIT`. `replaceAll` keeps the non-overlapping `split`/`join` count it reported before.
