# plugin-market code notes

`packages/boot/plugin-market/src/index.ts:PluginMarket.setIndexes`: the method replaces the whole list, so two windows that edited the same earlier view silently discarded each other's additions or removals. It now takes an optional second argument, the list the caller last read from `listIndexes`, in order. When that list differs from the current `listIndexes` URLs, the call fails with `plugin-market/index-conflict` carrying the current URLs under `indexes` and writes nothing, so the client can refresh and retry. The comparison and the Settings write run in one in-process queue (`indexWrites`), because without it two calls could both pass the comparison before either wrote. Omitting `expected` keeps the earlier last-write-wins behaviour for callers that have not been updated; the queue still orders those writes. The queue serializes one Host only: two Hosts sharing one profile directory are not coordinated, the same limit the package already documents for Settings writes. The shipped client (`packages/client/ui-plugin-market/src/client/market-store.ts:saveSources`) does not yet pass `expected`.

`packages/client/ui-plugin-market/src/client/market-store.ts:DiscoverController.saveSources`: the Client sends the URLs of its last loaded index list as `expected` to `setIndexes`. On `plugin-market/index-conflict` it does not retry with the same edit, since that would overwrite what the other window saved without the user having seen it: it reports `sourceFailure: { kind: 'changed' }`, keeps the draft and reloads the list through `loadIndexes` (a read of `listIndexes`, which carries titles and read errors that the error's `details.indexes` lacks). The user repeats the add or removal from the current list. A save issued before the first list has loaded sends an empty `expected`, which conflicts with a non-empty server list and reloads, so it cannot overwrite sources the dialog never showed. `packages/extensions/cordis-client-runner` has no `setIndexes` mirror, so no generated catalog there changed.
