`packages/client/ui-sidebar-terminal/src/client/CliTerminalPane.tsx:CliTerminalPane` (finding 269): the CLI conversation pane shares `TerminalView` and the terminal screen with the sidebar body but offered only Close, so a failed, disconnected or read-only attachment had no way to recover from that pane. The pane now renders the same recovery controls as `TerminalBody`: Take control for a running read-only attachment, Reconnect for a known process whose attachment failed or dropped, and Retry or Reconnect through `refresh` when no process was ever confirmed. `refresh` and `connect` only reattach to or discover an existing process, and `TerminalView::refresh` creates a process only for a fresh identity, so these actions never replace a confirmed or restored CLI process.
