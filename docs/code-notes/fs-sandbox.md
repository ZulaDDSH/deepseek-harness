# fs-sandbox code notes

`packages/fs/fs-sandbox/src/containment.ts:isPathUnder` (finding 255): the lexical fast path now compares the exact spelling only. A case-folded match used to be accepted on Windows without checking the filesystem, which let `C:\parent\repo\file.txt` count as inside the writable root `C:\parent\Repo` when the parent directory has the per-directory case-sensitivity attribute and the two siblings are distinct directories. Every non-identical spelling now goes through the filesystem-identity walk, which compares the root's device and inode with each existing ancestor of the target, so a case-insensitive directory still matches its differently cased alias while a case-sensitive distinct sibling is denied. The `caseSensitive` parameter was removed because identity, not spelling, is now the arbiter on every platform. A case-only spelling difference now costs a few stat calls instead of none, and a case-only match with a missing root is denied.
