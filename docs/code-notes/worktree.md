# worktree code notes

`packages/experimental/worktree/src/removal.ts:inspectRemoval`: eligibility used `git status`, which reports neither ignored files nor edits to files marked skip-worktree or assume-unchanged, and `git worktree remove` without force deletes all three, so archiving a Session could destroy local configuration, generated data or hidden edits that its branch does not hold. Inspection now also retains a checkout that lists any ignored file (`git ls-files --others --ignored --exclude-standard`) or any tracked file whose `git ls-files -v` tag is not `H` (skip-worktree is `S`, assume-unchanged is lowercase). This is deliberately conservative: a checkout with only regenerable ignored output such as `node_modules` is also retained, and `retainOnArchive` plus manual removal remain the way to clean those. Covered by `packages/experimental/worktree/tests/removal.spec.ts` and `tests/archive.spec.ts`.
