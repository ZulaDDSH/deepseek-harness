# workspace-files code notes

`packages/api/workspace-files/src/index.ts:Config.confineReads` and `WorkspaceFiles::locateFile`: `read`, `readBytes` and `stat` resolve absolute paths through the composed filesystem's read authority, so a principal granted them on one Session can read any Host file the process can read (issues.md finding 20). Remote methods receive only the Session-derived scope, not the caller's principal, so the service cannot tell an owner from a grantee. `confineReads` is the deployment switch: when true, `locateFile` resolves the path and requires `fs.contains(workspaceRoot, target)` (the same containment `list` uses, which follows links through `fs.resolve`), refusing with `workspace-file/outside-workspace`; the `baseFile` hop in `readBytes` and a file target of `changes` take the same gate because both go through `locateFile` / `WorkspaceChangeFeed::follow`. The default stays `false` because the owner UI previews files outside the workspace (tool-result paths, presented files, `ui-deliverables/src/present-open.ts` calls `stat` host-side) and LiveShare already classifies the three methods owner-only (`packages/experimental/liveshare/src/endpoint-classification.ts`); flipping the default is a product decision recorded as NEEDS NOMAD in the final report. Covered by `packages/api/workspace-files/tests/confine.spec.ts`.

`packages/api/workspace-files/src/changes.ts:ChangeFollower`: every instrumented `fs/observed` emission was appended to every follower's queue before the target filter ran, and the queue was unbounded, so one stalled subscriber retained all filesystem activity (finding 45). Every matching observation produces the same action (re-stat the target and yield its current metadata), so the queue is replaced by one dirty flag once the target key is known. Before the target resolves, observed target keys are kept in a set capped at `PRE_TARGET_LIMIT`; overflowing it marks the follower dirty, which costs at most one extra re-stat frame. Covered by `packages/api/workspace-files/tests/changes.spec.ts` ("coalesces ..." and "ignores unrelated ...").
