# Workspace Organizer

In the sidebar, right-click a workspace and choose **New partition**. Right-click a session in that workspace and choose **Move to partition**. Click a partition heading to collapse or expand it. Use **Manage partitions** in the workspace menu to rename or remove a partition. Removing a partition returns its sessions to the workspace list.

In **Settings → OpenCode Go accounts**, connect each OpenCode Go API key under a distinct account name. Choose a model in the account’s group in the chat model picker. Renaming an account preserves its provider ID. Keys are stored in the Harness credential store.

Run `npm pack` in this directory and add the tarball with `dsh plugin --profile desktop add <tarball>`. This plugin targets the Harness `0.2.2-rc.5` desktop runtime.
